# AGENTS.md

Guidance for agents and contributors working in this repository.

## Always bump the version before building/releasing

The extension **must** get a new version on every build that may be shipped or
uploaded to a store. Both the Chrome Web Store and AMO reject re-uploading a
version that already exists, so never build a release without incrementing.

Increment the **patch** version (e.g. `0.8.1` → `0.8.2`) and keep every copy in
sync before running the build:

1. Bump `package.json` + `package-lock.json` (no commit/tag):
   ```bash
   npm version patch --no-git-tag-version
   ```
2. Update the same version in:
   - `chrome/manifest.json` → `"version"`
   - `mozilla/manifest.json` → `"version"`
   - `chrome/src/ui/popup.html` → header (`vX.Y.Z`) and the About row
     (the `mozilla/` copy is regenerated by `npm run build:firefox`)
   - `store/listing.md` (the "Version X.Y.Z" line)
3. Verify: `npm run build` prints "version X.Y.Z matches package.json" for both
   packages.

`scripts/pack-extension.js` fails the build if the manifest version and
`package.json` version disagree, so a missed update blocks packaging.

Optional: a patch bump that only changes runtime code does not need a minor/major
bump. Reserve minor/major for feature/breaking changes and call it out in the
commit message.

## Build & test

```bash
npm run build          # bundle + pack chrome/ and mozilla/
npm test               # crypto + handler unit tests (Node)
npm run test:e2e       # Selenium smoke test against LibreWolf
npm run lint:firefox   # web-ext lint (AMO rules)
```

## Do not edit generated files

- `chrome/src/background-bundle.js` and `mozilla/src/background-bundle.js` are
  generated by `npm run bundle` (esbuild). Edit the sources under
  `src/background/` and `src/crypto/` instead.
- `mozilla/` runtime files are synced from `chrome/` by
  `scripts/sync-firefox.js` (run automatically by `npm run build:firefox`).
  Edit the `chrome/` copy.

## Commits

- Only commit when asked.
- Commit signing is enabled; make sure the GPG agent is unlocked before
  committing, or the commit will fail on pinentry timeout.
- Tag releases as `vX.Y.Z` (e.g. `git tag -a v0.8.1 -m "ciphertext v0.8.1"`).
